# STEVO POS Frontend

This is the React frontend for the STEVO POS Suite application, built with Vite. It provides the dashboard UI for managing products, orders, reports, users, and store settings.

## Overview

The frontend consumes the Express API from the backend and presents a modern POS dashboard with:

- Overview analytics cards
- Product management
- Order creation and tracking
- Reports and export actions
- Settings and notification panels
- Role-based navigation and access rules

## Running locally

From the frontend folder:

```bash
npm install
npm run dev
```

Then open:

```text
http://localhost:5173
```
